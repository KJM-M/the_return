# The Return

An atmospheric fantasy text adventure built with Unity and C#.

Explore a mysterious island, examine your surroundings, collect and combine items, speak with its inhabitants, and uncover a way off the
island.

## About the Game

The Return combines classic command-driven text adventure gameplay with illustrated locations, character dialogue, environmental puzzles, and
a complete beginning-to-end storyline.

### Features

- 17 interconnected locations
- Illustrated scenes and item interactions
- A graphical inventory
- Collectible, usable, and combinable items
- Multi-stage character conversations
- Environmental puzzles and hidden discoveries
- Paths and artwork that change as you progress
- Command history and an in-game help interface

## How to Play

Type a verb followed by a noun when needed.

Available commands:

- `go [direction]` — Travel in a direction
- `examine [item]` — Look at something more closely
- `get [item]` — Pick up an item
- `use [item]` — Use an item
- `combine [item] [item]` — Combine two items
- `give [item]` — Offer an item to someone
- `read [item]` — Read writing or inscriptions
- `talkto [character]` — Speak to someone
- `say [word]` — Say a word aloud
- `exitgame` — Exit the game

Examples:

- `go north`
- `examine staff`
- `get lantern`
- `read plaque`
- `combine lantern matchbox`
- `talkto ferryman`
- `give golden coins`

Examining your surroundings is important. Many items, clues, and routes are discovered through observation and experimentation.

## Run from Source

1. Clone or download the repository.
2. Open the project in **Unity 6000.6.6f1** or a compatible version.
3. Open `Assets/Scenes/Main.unity`.
4. Press **Play**.

The project uses Unity UI and TextMesh Pro. Dependencies are included in the project's package configuration.
